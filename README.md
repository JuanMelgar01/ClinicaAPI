\# ClinicaAPI



\## Descripción

Proyecto de la asignatura \*\*DWES (Desarrollo Web en Entorno Servidor)\*\*.

API desarrollada con \*\*Spring Boot\*\* para la gestión básica de una clínica.



\## Tecnologías utilizadas

\- Java

\- Spring Boot

\- Maven/Gradle (según proyecto)

\- REST API



\## Estructura del proyecto

\- `src/main/java/` Código fuente

\- `src/main/resources/` Configuración y recursos

\- `pom.xml` Dependencias (si usas Maven)
